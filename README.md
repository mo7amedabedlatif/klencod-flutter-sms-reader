# دفتري (Daftari) - Flutter

دفتر ديون للتجار، بالعربي، بدون سيرفر. بيقرأ رسائل البنك على جوال التاجر (أندرويد) وبيأشّر الدفعة "واصلة" لحاله.

## التركيب

```bash
flutter create --org com.daftari --project-name daftari daftari
cd daftari
# انسخ فوق المشروع: pubspec.yaml ومجلد lib ومجلد test من هالملف المضغوط
flutter pub get
```

## صلاحيات الأندرويد (ضروري)

افتح `android/app/src/main/AndroidManifest.xml` وضيف قبل وسم `<application`:

```xml
<uses-permission android:name="android.permission.RECEIVE_SMS"/>
<uses-permission android:name="android.permission.READ_SMS"/>
<uses-permission android:name="android.permission.READ_PHONE_STATE"/>
<queries>
  <intent>
    <action android:name="android.intent.action.VIEW"/>
    <data android:scheme="https"/>
  </intent>
</queries>
```

## التشغيل

```bash
flutter test                 # فحص الدوال الأساسية
flutter run                  # تجربة على جوال أندرويد موصول
flutter build apk --release  # ملف APK للتاجر: build/app/outputs/flutter-apk/app-release.apk
```

## قبل التجربة مع تاجر

1. من **الإعدادات** عدّل القوالب الوهمية (BANKA و WALLETB) لتناسب رسائل بنكك الحقيقية. لازم الـ Regex فيه المجموعات: `(?<amount>..)` و `(?<name>..)` و `(?<op>..)`.
2. غيّر `kCountryCode` أعلى `lib/main.dart` (970 أو 972).
3. جرّب أولاً بخانة "الصق رسالة بنك" قبل الاعتماد على القراءة التلقائية.
4. على شاومي وسامسونج: عطّل توفير البطارية للتطبيق وفعّل "التشغيل التلقائي"، وإلا بيموّته النظام بالخلفية.
5. التطبيق بيلحق الرسائل الفايتة عند فتحه (آخر يومين أول مرة)، وما بتنحسب حوالة مرتين.

## كيف بيشتغل

- رسالة بنك توصل → فلتر المرسل → تجاهل رموز التحقق → تحليل بالقالب → تجاهل المكرر.
- مطابقة: نفس المبلغ بالضبط + دفعة بنك معلّقة خلال 48 ساعة. وحدة بس = تأكيد تلقائي. أكتر من وحدة = بتنتظر اختيارك. ولا وحدة = قائمة "حوالات بدون صاحب".
- الدين ما بينقص من دفعة البنك إلا لما تصير "مؤكدة".
- ما في حذف: الرفض تغيير حالة، وكل تعديل مسجّل بجدول `audit_log`.
- ما بينخزن نص الرسائل ولا أرقام الحسابات، فقط المبلغ والاسم والرقم المرجعي.

## حدود النسخة الأولى

- أندرويد فقط (الأيفون ما بيسمح بقراءة الرسائل؛ الصق الرسالة يدوياً).
- بدون إشعارات خارج التطبيق (المطابقة بتصير بالخلفية، وبتشوفها لما تفتح التطبيق).
- البيانات محلية على الجوال، فلازم نسخ احتياطي (خطوة قادمة مهمة).
- جوجل بلاي بيقيّد صلاحية قراءة الرسائل، فوزّع الـ APK مباشرة.
